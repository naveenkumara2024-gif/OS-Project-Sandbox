# Fuzzing

Stage 1 fuzzes the launch-spec parser (`native/src/spec.c`), the helper's only untrusted-input
parser (CLAUDE.md 5.5). The TypeScript request parser is covered by fast-check properties in
`tests/unit/request.test.ts`; Jazzer.js is deferred to Stage 5 (prompt section 11, item 4).

```bash
node scripts/build-native.mjs fuzz --cc=clang      # needs libclang-rt-<N>-dev
mkdir -p /tmp/spec-corpus && cp corpus/spec/* /tmp/spec-corpus/
../../native/build/fuzz/fuzz-spec -max_total_time=300 -max_len=70000 /tmp/spec-corpus
```

- `corpus/spec/seed-*` are generated by `node scripts/gen-fuzz-seeds.mjs` from the real encoder.
- `corpus/spec/regression-*` are inputs that once tripped the harness (an invariant that was too
  strict), kept so the fix cannot regress.
- The remaining files are libFuzzer's minimised coverage corpus (`-merge=1`).
- A crash is a finding: stop and report it (CLAUDE.md 7). Never delete a crashing input.
